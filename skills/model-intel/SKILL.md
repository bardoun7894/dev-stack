# model-intel

Zero-AI pipeline in `scripts/` (python3 stdlib + bash). The only model call is one Haiku summary in `weekly.sh`.
Data lives in `data/` (git-ignored): `latest/` (symlink to `snapshots/YYYY-MM-DD/`), `reachable.json`,
`recommendations.md`, `changes/`, `proposals/`, `weekly.log`.

## Answering a model question

0. Read `~/.claude/reference/model-picks.md` first (short picks, generated by `scripts/render_picks.py`).
1. Then `data/recommendations.md` for detail. It has the per-use-case pick (model, effort, AA index, cost per task,
   tok/s, provider), the effort ladder per family (where the next level stops paying), top media models and the
   PixVerse check. Quote it; do not browse leaderboards.
2. Need a number that is not there: `data/latest/llm.csv` (every effort variant) or `data/latest/media_*.csv`.
3. Snapshot older than 8 days: run `bash scripts/weekly.sh` (or just `python3 -I scripts/fetch.py && python3 -I scripts/recommend.py`).

## Running by hand

```bash
bash ~/code/dev-stack/skills/model-intel/scripts/weekly.sh      # full run; exit 0 ok, 1 fetch failed, 2 router changed
python3 -I scripts/fetch.py                                      # snapshot only (AA_API_KEY set = official API first)
python3 -I scripts/diff.py                                       # latest vs previous
python3 -I scripts/recommend.py                                  # reachable.json + recommendations.md
python3 -I scripts/render_picks.py                               # ~/.claude/reference/model-picks.md (MODEL_PICKS_OUT overrides)
python3 -I scripts/propose_tiers.py --dry-run                    # what would change; no write
MODEL_INTEL_TIERS=/tmp/tiers.json python3 -I scripts/propose_tiers.py   # test on a copy, never the real file
```

Fetch fails loudly (exit 1) and keeps the previous `latest` if any file loses more than 30% of its rows.

## Router updates

`propose_tiers.py` auto-applies to `~/.config/jev-router/tiers.json` only when ALL hold: the model is new to the file,
reachable through a subscription provider (never openrouter/metered), beats the chain head by >= 2 index points at
<= its cost per task (or equal index at <= 70% cost, and not under 70% of its speed), the chain is not owner-pinned,
and a live probe passes. The new entry is inserted ahead of the incumbent (the incumbent, and the last Claude entry,
stay as fallback). Backup `tiers.json.bak-model-intel-DATE`, jq + jdelegate dry-run validation, restore on failure.
Everything else goes to `data/proposals/DATE.md` for the owner. Pinned = the chains in
`config/owner_rules.json` `pinned_entries.chains` (plus the first two Opus/Sonnet entries of T3/T4), or listed in an
optional structured `_pinned` array in tiers.json. Free text in `_comment` is never parsed: rewording a note cannot
unpin anything.

## Owner rules (also in config/owner_rules.json)

- Arabic copy: GPT first, Gemini fallback. GPT only for review and language work, never implementer chains.
- Opus is never a worker; Fable is not used.
- MarktingTeam video stays PixVerse. Report better options, never auto-change.
- Arabic text in images is an overlay added afterwards, never rendered by the image model.
- Subscriptions first (cliproxy, openai-codex, opencode-go, commandcode), openrouter last.
